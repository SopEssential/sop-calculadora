# Sop. Calculadora

Calculadora de preus per impressió 3D — Sop. Essential

## Instal·lació

Disponible a: https://sopessential.github.io/sop-calculadora

### Mòbil (iOS / Android)
1. Obre l'enllaç al navegador
2. iOS: Compartir → Afegir a la pantalla d'inici
3. Android: Menú → Instal·lar app

### Ordinador (Chrome / Edge)
1. Obre l'enllaç
2. Icona d'instal·lar a la barra d'adreces (⊕)
3. Instal·lar

## Funcionalitats
- Calculadora de preus per peça (material, electricitat, manteniment, marge)
- Gestió de comandes amb múltiples peces
- Historial de comandes guardat
- Agenda de clients
- Generació de factures PDF
- Sincronització amb Google Drive
